默认下载帖子中的第一个视频；链接含 /video/2 等编号时下载对应视频。X 默认使用匿名模式。

在所选上限内选最佳版本；实际画质取决于视频源，不会放大低分辨率视频。

保留源音轨编码，避免额外损失；文件扩展名由源格式决定。

先下载源视频，再转换所选片段；不足指定时长则到片尾结束。GIF 无声音，较长、较大的动图会占用更多空间。

只下载字幕文件，不下载视频。优先人工字幕，可包含站点自动生成的字幕；不生成新字幕。Bilibili 弹幕不属于字幕。全部语言可能产生大量文件。

仅对支持的 DASH / HLS 分片生效；普通 HTTP 文件不增加连接数。并发越高不一定越快。

本地桥接 · 尚未检测

检测 yt-dlp、FFmpeg 和下载目录。缺失时自动下载并校验，首次安装需联网。需先安装本地 Host。

先检查版本，再选择更新。不会自动降级。

更新仅切换 VideoBridge 使用的 yt-dlp，保留原工具和上一版本。FFmpeg 仍通过“检测并补齐依赖”补齐。

关闭弹窗后任务继续；退出浏览器会停止任务。

适用于 yt-dlp 支持的媒体页面，也会尝试通用提取。每次仅下载一个条目；会员、地区、DRM 等限制仍可能影响结果。
