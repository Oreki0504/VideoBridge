VideoBridge Installation Guide

Videos, audio, GIFs and subtitles, saved locally.

Next: load the browser extension

  1. In Chrome, open chrome://extensions; in Edge, open edge://extensions.
  2. Enable Developer mode and select Load unpacked.
  3. Select the installed folder below:

Setup has prepared this folder; no manual extraction or copying is needed. VideoBridge is not yet available in the Chrome Web Store, so the extension must be loaded manually once.

Start downloading

Open a YouTube, Bilibili, Niconico or other media page and click VideoBridge. Choose video, audio, GIF or subtitles. For content requiring login, grant site access and enable Use current site session. Availability depends on yt-dlp and the site's access rules.

If tools are missing, open Local Bridge and select Check & Install Dependencies. If Setup reported a failure, run Setup again after resolving it.

The popup follows your browser language on first use. Use its EN / 中文 button to switch languages; your choice is saved.

Upgrade or move an existing installation

If you previously loaded VideoBridge from a project or extracted folder, remove that old extension before loading the installed folder above. Downloads and local tool settings are preserved. Grant site permissions again for the new extension.

For future upgrades, run the new installer and reload the extension. Uninstall from Windows Installed Apps or the VideoBridge Start menu folder. Downloaded files, settings and managed tools are kept; remove the browser extension separately.

Program files are stored together in your VideoBridge installation folder. Existing download folders are preserved; new installations default to Downloads\VideoBridge in your user profile.
